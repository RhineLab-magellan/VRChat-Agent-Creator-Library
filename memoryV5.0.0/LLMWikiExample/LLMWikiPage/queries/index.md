# Queries — 查询归档索引

> LLM Wiki Query 分区：收录值得保留的优质查询结果（实质对比、深挖、新颖综合）。琐碎查询不归档。

## 归档规则

- **何时归档**：回答需要综合 3+ 页面、或包含新颖综合/对比结论
- **何时不归档**：单页即答的琐碎问题、纯事实速查
- **命名**：`YYYY-MM-DD-<主题>.md` 或 `<主题>-query.md`
- **结构**：问题 → 答案 → 引用页面列表（wikilink）→ 结论
