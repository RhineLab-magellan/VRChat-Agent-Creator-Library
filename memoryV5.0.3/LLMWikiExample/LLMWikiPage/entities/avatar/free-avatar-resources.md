## ⚠️ 重要提示

**使用前务必检查每个 Avatar 的 TOS/TOU(服务条款 / 使用条款)**

- 协议因创作者而异(CC0、CC-BY、商业、Private Use 等)
- 部分免费 Avatar 仅供个人使用, 不能用于 Public Avatar(发布给其他玩家)
- Public Use 需创作者明确许可

详见: [[entities/avatar/legal-and-licensing]]

## 6. 注意事项

### 6.1 上传前检查
- [ ] Avatar TOS/TOU 明确允许 Public Use
- [ ] Avatar 包含必要 VRChat 组件(VRC Avatar Descriptor)
- [ ] Rig = Humanoid 已配置
- [ ] 骨骼映射正确(Jaw 不分配, 见 `avatar-upload-getting-started.md §4.4`)
- [ ] 材质已提取, Shader 已设置

### 6.2 已知风险
- 部分免费 Avatar **未配置 VRChat** - 需自行配置
- 部分 Avatar 骨骼映射**未优化** - 可能需调整
- 部分 Avatar **过时** - 缺少 PhysBones / Avatar 3.0 支持

详见: [[entities/avatar/avatar-upload-getting-started]]

### 6.3 长期维护
- 链接每 6 个月验证一次
- 关注新资源站(CC0 协议优先)
- 关注 s-ilent / ToxSam 等活跃维护者
