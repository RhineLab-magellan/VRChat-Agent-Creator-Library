# VRC 委托模型定价参考（定性分级）

> ⚠️ **定性说明**：本文档仅提供**定性分级**（预算低 / 中 / 高三档），**不含具体价格数字**；实际报价以市场行情为准。

> Domain: Avatar | 适用: 委托模型前的预算决策
> 来源: 86vrchat 中文社区

> ⚠️ **[INFERENCE]** 以下价格区间为**社区经验**,无统一标准,仅供预算参考

---

## 1. 三档价格区间

**[COMMUNITY-86vrchat]** 按复杂度划分:
(来源: https://docs.vrcd.org.cn/books/86vrchat)

### 1.1 低预算:改瞳/改眼仁

| 项目 | 描述 |
|------|------|
| **基础** | 以体型接近的 booth 量贩模型为基底 |
| **改造** | 把瞳孔调成角色颜色,或移植眼仁贴图 |
| **配套** | 按人设买接近公式的衣服 |
| **适合** | 简单 OC、人棍试水 |

### 1.2 中预算:加头发和衣服(推荐)

| 项目 | 描述 |
|------|------|
| **基础** | 以体型和表情风格接近的模型为基准 |
| **改造** | 定制 OC 的发型和服饰 |
| **工具选择** | 见 §2 |
| **适合** | 大部分 OC 创作者 |

### 1.3 高预算:三视图从头捏

| 项目 | 描述 |
|------|------|
| **基础** | 牢模型师(经验丰富的建模师) |
| **精度** | 最高 |
| **预算** | 充足推荐 |
| **适合** | 商业级 OC、长期项目 |

---

## 2. 中预算的工具选择

**[COMMUNITY-86vrchat]** 三种工具链对比:
(来源: https://docs.vrcd.org.cn/books/86vrchat)

| 工具 | 特点 | 价格 |
|------|------|------|
| **Blender** | 从头做,精度最高 | 价格最高 |
| **VRoid** | 美术力大砖飞 | 中等 |
| **恋活(koikatsu)** | 灵车(捏人游戏导出) | 低 |

> **[UNKNOWN]** "恋活是灵车"为社区调侃,实际涉及 illusion 系游戏的合法性争议

---

## 3. 决策树

```
预算
├─ 低 → 量贩改瞳(简单 OC)
├─ 中 → 量贩 + 定制发型/服饰
│   ├─ Blender(从头做)
│   ├─ VRoid(快速成型)
│   └─ 恋活(争议,谨慎)
└─ 高 → 三视图从头捏(商业级)
```
